# Autoria e fontes

| Recurso | Autoria / fonte | Uso |
|---|---|---|
| Kit de pré-produção, mapa e concept arts | Fornecidos pelo usuário | Documentação e referência; não são meshes nem cenário raster de runtime; direitos originais preservados |
| `nico.glb`, `porteiro.glb`, `box.glb` | Modelagem procedural original deste projeto em Blender 4.3.2 | Meshes 3D reais, fonte reproduzível `tools/build_models.py` |
| `bellmare-atlas.png` | Gerado com `image_gen`, baseado nas referências fornecidas e revisado para cartoon 3D a pedido do usuário | Materiais de parede, carpete, porta e madeira, amostrados por UV; não substituem o mapa 3D |
| Primitivas adicionais, placas e animações | Código original deste projeto | Runtime PlayCanvas, pivôs de peças, texto editável |
| SFX | Síntese original por Web Audio | Sem gravação/serviço externo, sem microfone |
| Fontes | Georgia/Arial do sistema | Nenhum arquivo de fonte redistribuído |
| PlayCanvas Engine | PlayCanvas Ltd., MIT — https://github.com/playcanvas/engine | Engine e primitivas; licença incluída na dependência/bundle |
| Blender | Blender Foundation, GPL — https://www.blender.org | Ferramenta local de autoria; modelos originais exportados, Blender não é dependência de runtime |
| Vite / Vitest / Prettier | MIT | Ferramentas de desenvolvimento |
| TypeScript / Playwright | Apache-2.0 | Ferramentas de desenvolvimento/testes |

Não houve download de modelos protegidos, compra de assets, criação de contas, uso de API paga, TTS online ou publicação externa. Modelos e atlas foram feitos para este projeto; a fidelidade final às concept arts não foi declarada. `evidence/cartoon-models-blender.png` é revisão de modelos em estúdio, separada da evidência de gameplay no navegador.
