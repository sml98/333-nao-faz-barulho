Download and install instructions from Quaternius:

First-Time Setup for Source Version

The first time opening a project is going to be slower, due to the engines having to remake the cache/temp files which are deleted to make the projects lighter, after that it will open as any other project.

UNREAL ENGINE:

The kits are developed in an older version of Unreal Engine to let people who are not using the latest version still use the kit. If you use a newer version you need to follow these two steps just the first time you open it.


The Unreal Engine models were exported in GLTF because of a known scaling bug when importing rigged FBXs from Blender. It recognizes the units wrong and breaks retargeting in some cases.

Strongly suggest also using GLTF if you want to re-export.

To import just drag and drop the .glTF.
